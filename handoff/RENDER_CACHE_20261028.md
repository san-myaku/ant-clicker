# 地形の差分描画と部屋セル分類の共有 — 採用結果

2026-10-28、codex/ant-1000-plan-20261027。比較元05fb0e2（姿勢キャッシュの数値化済み）。

前回の描画込み通常速度が約0.39倍に留まったことを受け、地形全体の再描画と、部屋名の位置計算での全体走査を改善した。固定コマのモデル+描画は活動512匹で約19%減、新需要512匹で約57%減。42ケースの全画素/全保存一致と全35本の回帰を終えて採用した。

## 実装の範囲

- build-room-cells.cjs: grainRoomの0〜255という現行契約で、空いている砂粒が4個以上ある粗いセルを、全ての部屋について一度の走査で分類。looseセルを除外し、各部屋の返すセルの順序と同revision内の配列再利用、存在しない部屋の空配列を維持する。部屋名の位置だけを近似したり、部屋を省いたりしていない。
- build-ground-cache.cjs / ground-cache.js: 描画前の砂粒/部屋タグと、前回の光を保持。revisionが変わった時に実配列を比較し、変わった粒と隣の壁、部屋の床色が変わる粒を更新対象にする。イベント通知を取り逃がす方式ではない。
- 空洞の追加では光の値13から隣へ1ずつ減る従来の伝播を使い、値が増えた場所だけを更新。新しい固体による遮光や新しいSimulationでは従来の全再生成へ戻す。初回の全描画は残る。
- 更新する横並びの粒をまとめて元のearthLayerから復元し、従来と同じ色/半透明の影/壁/床をCanvasで描く。色の近似計算や砂粒の間引き、描画遅延で速さを作らない。floorLayerは全再生成用に残し、通常の差分はgroundへ同じ不透明な床色を描く。
- キャッシュは描画専用で、保存形式へ入れない。描画用の砂粒/部屋タグのコピーは各138,240bytes、計276,480bytes。dirty配列は一時138,240bytes。全メモリの増減は測定していない。既存の姿勢キャッシュの3MiBも継続する。
- core.js/view.jsは直接編集せず、build.cjs/build-view.cjsと新しい編集元からnpm run buildで生成。game.js/lifecycle.jsは前版と同一。土/卵/餌/アリ/物理/輸送/予約の省略はない。

## 回帰と証拠

- verify-render-cells: 3保存、全ての既存部屋/0/254/255/無効番号、空配列の再利用、loose、部屋タグとrevisionの変化を旧版へ照合。順序/全保存が一致。
- verify-ground-browser: DPR2、6保存の読込/自然3秒の継続/fit、1440/320pxへのresizeとzoom、3seed、掘削/部屋タグ/用途/固体追加、実UIでのresetの計42ケース。地形のRGBA全画素、光配列、画面キャンバス、全保存のhashが一致。合成の描画状態は正規保存へ変換/復元せず、最後に正規の新しい巣へresetする。
- 画素比較の参照は05fb0e2のindex/core/lifecycle/game/viewをqa/render-referenceへhash付きで凍結。QA用HTTPでだけ内部の画素/照明を観測するフックを挿入し、製品へ検査APIを追加していない。
- 採用後に、各観測直前にrenderを呼ぶ追加検査でも同じ42ケースの全画素/光/画面/全保存を照合し一致。rAFを停止した標準検査では、fit/zoom/resetなどの値変更の直後に描き直していない場合があるため、新しいフレームも確認した。追加検査のソース/実行結果/PNGはfresh-pixels/へ保存し、ゲームと全35本で検証した標準検証のソースは変更していない。次の全体検証更新時にこの観測手順を標準へ統合する。
- 別コピーでnpm run build→verify-all.cjs --browser --chainの全35本が881.280秒で合格。モデル/育成とブラウザは従来通り分離実行。検証中の117ソース/32入力と元本体のソースは不変。

## 初回の検証スクリプトの失敗

最初の画素比較では設定を開く前に隠れているresetボタンをclickし、可視性待ちでタイムアウトした。画素の不一致やゲームの停止ではない。原スクリプトと失敗をr1-ui-failedへ保持し、DOM通りに設定を開く実操作を追加して全ケースを初めから再実行した。force click、製品のUI変更、期待値の緩和はしない。PROJECT_CONTEXT失敗34にも記録。

初回の全体実行では256匹の6秒/1ゲーム秒超の条件が不合格になり、512匹ブラウザ中に実行セッションを失って終了記録も残らなかった。その実行は全体合格としていない。r2-full-interruptedへ保持。単独の再診断では旧版が実6.183秒で15ゲーム秒、候補が実6.207秒で30ゲーム秒進み、両方合格した。停止/非表示/代替rAFは再診断時には無く、初回原因は未確定。環境原因と断定しない。元の検証へ不合格時のbefore/after/errorsを出すメッセージだけ追加し、同じ6秒/1秒超の条件で全35本を初めから再実行して合格した。長い実行の開始時に117ソース/32入力を耐久的に記録するようにし、完了記録の無い実行と区別する。PROJECT_CONTEXT失敗35にも記録。

また、rAFを止めてUIを操作した際、カメラ値の変更と実描画の完了は同じではないことを確認した。既存の全地形RGBA照合に加え、観測直前に描画する追加検査で、カメラ/リセット直後の画面も旧版と照合した。PROJECT_CONTEXT失敗36に、古いキャンバスを比較して合格にしない観測手順を記録。
