## 接続した範囲

`build.cjs` が正本の `../../index.html` から確認版を生成する。既存コードに名前を確認したフックを挿入し、元本編を編集しない。再生成は `node prototypes/clicker-integration/build.cjs`。生成HTMLを直接編集しない。

`sprites.js` は育成循環の試作の短い脚/触覚と地表の横姿の描画を抜き出したもの。`core.js` は `../colony-game/core.js` を既存サーバーから配信し、その `Physics.World` を利用する。元試作や育成循環のシミュレーションは同時に進めない。

`nest.js` が本編の建築対象を受け取り、初期形状/表示/実掘削を2 CSS px四方の粒へ揃える。露出した1〜4粒を一粒ずつ削り、同じ物体IDのまま口元へ移す。本人が地表へ運び、物理世界へ下ろした粒数だけ建築進捗を計上する。全対象粒の配送後に既存の完成処理で可視化/容量/解放を更新する。人数だけの建築進捗加算は止める。

`world-plan.js` の新規配置は、第1層だけで研究前400匹へ育つ小さな部屋と接続を用意する。旧保存は旧形状を維持。`geology.js` の固定seed/境界/岩/鉱脈から色・硬さ・必要研究を共通判定する。`exploration.js` は実空洞と短い壁際だけを照らし、安全に本人が到達した深さ、実搬出の一度だけの発見報酬、研究後の実採掘地点からの収入を扱う。予定の部屋や研究購入で先を見せない。用途/予約/実費用は本編へ返す。

メニューの速度は1〜10倍で保存される。ゲームと物理を1/60秒刻みで進める。端末負荷によって実効速度は変わる。

運搬経路は実際の空洞で探索し、荷を含めた余裕のある帰路を確認してから仕事を選ぶ。地表の土には重力と積み重ねがある。元本編の食料/育児/戦闘の数値計算は維持しており、全資源の物理化は含めていない。

仕上げの角で作業姿勢が取れない場合は、近傍の土を実際に掘り広げて運ぶ。追加の土も配送してから完成を判定する。お宝の抽選は実配送で進む2%刻みへ接続し、完了時の抽選と合わせて旧本編の50回相当を維持する。

## 保存

元本編の6キーと別originの保存を保護する。主キーは `grainClicker_1_antSimV23_0`。進行と知見/恒久研究をまとめた `ant-clicker-grain-save` / schema 1 を保存し、内側は地質/探索を含む `clicker-grain-2`。以前の確認版grain-1の途中状態と知見は、検証して形/担当/荷物を維持し引き継ぐ。古い通常/転生キーへの自動フォールバックは行わない。

粒地形、工事の対象/進捗/候補探索位置、仕事の段階、担当IDと位置、実荷物、物理状態、時計、元の部屋の頂点/配置点、地表を同時保存する。座標の端末倍率差を読み込み時に換算する。旧本編の保存読込時の再中心化/圧縮とランダム形状の再生成を、粒保存には適用しない。

入力を採用前に検証し、現在の状態を書き出す。重要操作/離脱/非表示と30秒ごとに保存する。知見と巣を一度に置き換え、読込/転生/やり直し前の状態も一つ保持する。保存失敗時の表示/書出し/再試行、読めない保存の上書き防止も追加。詳細は [保存の土台](SAVE_SAFETY.md)。全役割の仕事や終盤/放置の復元完成とは区別する。

## 残る工程

- 通路/部屋の完成予定形状を、試作14の需要と地形から育つ形へ接続する。新規は小さい配置へ整理したが、接続と用途の計画は固定。
- 建築時間と研究/人数の効き方の調整。従来の数式建築とは所要時間が異なる。
- 大人口の扱い。元本編の代表アクター/群れ表示を維持し、全個体を実シミュレーションへ変更していない。画面上で働く建築係が実作業を行う。
- オフライン建築。未接続の2研究は購入を止めて準備中と表示する。その他のオフライン資源/育成は元本編の仕様。
- 大量の運搬粒の保持/長時間負荷、後半全研究/戦闘/崩落等との網羅的な相互作用、旧保存の正式移行、実機iPhone確認、公開版への切替。

通常の他役割の移動と局所的な重なりは元本編の仕様。岩塊は共通地質へ追加したが、必須の予定通路から離して配置する。試作14の全交通規則/需要から育つ計画を丸ごと移植した段階ではない。
