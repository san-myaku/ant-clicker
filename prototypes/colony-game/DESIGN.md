# 育つ循環 — 最初の実装

2026-10-20。統合計画の工程1をユーザーが採用。公開版・試作14を残し、`/play/` に独立した新本編の入口を置く。

## 遊び

- 働き手12匹、卵3個、餌6個、女王室から開始。餌は1個=幼虫への給餌1回。
- 採集係は地表の餌を取り、同じ物体を巣へ運ぶ。育児係は餌を実際に幼虫まで運び、そこで消費する。
- 卵→幼虫（2回給餌）→蛹→働き手。同じ卵のIDを追跡し、羽化時に実在の働き手を1匹だけ生成する。
- 自動産卵と「産卵を助ける」、3役の配分、実在の在庫を消費する3種の小さな強化を用意する。
- 必要な育児・貯蔵面積は実物と働き手数から算出。追加需要ボタンは置かない。割当変更時は現在の荷を運び終えてから同じ個体の役割を変える。
- 食料不足では成長・産卵を待つ。餓死はこの段階では導入せず、配分変更で回復できる。地表の採集場所には時間で餌が補充される。
- この区画は実在する64匹まで。大人口・死亡・戦闘・研究全体・旧保存移行・閉じている間の進行は後工程。

## 画面（コード着手前の構成）

既存試作を視覚の基準とする Modern Gray Utility の Workspace + Inspector。

```text
PC: [ありクリッカー / 育つ巣]              [一時停止][速度]
    [次の目標 / 不足しているもの]
    [                               ][働き手・卵・幼虫・蛹・餌]
    [          巣の観察              ][産卵を助ける / 進捗]
    [                               ][採集・育児・掘削  − 数 ＋]
    [                  拡大・全体   ][強化 / 選択した対象]
    [                               ][できごと / 保存（開閉）]
スマホ: 同じヘッダー → 巣 → 育成と役割 → 強化・詳細。
```

主操作は産卵と配分。保存・新規開始は折りたたむ。追加需要や物体をつまむ操作は通常のゲームから外す。数値は実在庫・個体の集計。灰色の面と罫線、4px角丸、操作40px以上。強調色は不足と主操作に限定。

## 実装・検証の境界

試作14の地形・物理・移動を `core.js` の出発点として固定コピーし、新ゲームだけを育てる。試作14は安定版として保持。新ゲームの台帳と行動は `game.js`。保存は `antColonyGame_1` のみ。元ゲームの生産・オフライン処理は走らせない。

採餌→給餌→羽化→需要増→掘削、役割の実効差、餌と卵の保存則、運搬中・給餌中・成長前後の保存継続を検証。デスクトップ・モバイル幅で画面と操作を確認する。実機iPhoneと大人口性能は完了条件に混ぜない。
