## 遊べる内容

女王室・入口、働き手12匹、卵3個、餌6個から開始。地表の餌を採集し、本人が持ち帰る。育児係は実在の餌を幼虫へ届け、そこで1個を消費。同じ卵のIDを卵→幼虫→蛹と追い、羽化時に実際の働き手を1匹生成する。働き手と在庫が増えると育児室・食料庫の需要も増え、掘削係が通路・部屋を掘って実粒を地表へ運ぶ。

- 産卵は通常40秒、手助けで4秒進める（0.35秒の間隔）。餌2個以上、育児中の数と総定員の空きが必要。産卵休止も可能。
- 卵35秒→幼虫へ2回給餌（20秒以上の間隔）→成長50秒→蛹50秒→羽化。時間はゲーム内秒。育つ速さの強化は各成長時間に反映。
- 地表の採集場所に8秒ごとに餌を1個補充、未採集は最大5個。補充はコロニーの在庫へ加算しない。餌1個=給餌1回。働き手の維持費と餓死は未導入。
- 採集/育児/掘削の人数を振り替える。本人のIDを維持し、進行中の荷と仕事を終えてから交代。新生個体は選んだ配分に従い、0匹にした担当へ勝手に配属しない。
- 強化は歩速+15%、成長速度+20%、掘削速度+25%を各3段階。初回の費用は実在する餌8/6/6個、段階ごとに倍・3倍。運搬中・予約中の餌は購入に使わない。
- 育児室需要は `max(5, 育児中の実数+ceil(働き手/3))`、食料庫は `max(10, 実在する巣内の餌, ceil(働き手*1.2))`。実物の受入先は通れる部屋の空きに応じ、足りない間は女王室へ仮置き。
- 働き手＋育児中が64まで。全働き手は実在する個体。この定員は初期区画のルールで、大人口の性能保証ではない。

## 実装と保存

`core.js` は安定した試作14から分岐した新本編用の地形・物理・移動。試作14は凍結した観察用として残し、今後の育成実装はここを育てる。`game.js` は個体/育児/餌台帳、行動、配分、購入。`view.js` はCanvasと操作画面。`DESIGN.md` に着手前の設計・画面構成。

新しい形式 `ant-colony-1`、保存キー `antColonyGame_1` のみを使用。30ゲーム内秒ごとと画面を隠す際に保存する。書き出し/読込/不正ファイル拒否に対応。閉じている間は進まない。

元の `antSimV23_0`、`antSimV22_2`、`antResearchMeta`、`ant_render_settings_v1`、`ant_research_view_v1`、`antPrestige`、試作の `antLivingNestPrototype_14` は読み書きしない。旧本編の毎秒食料加算やオフライン収益は動かさない。新本編・試作の保存の相互読込と旧本編移行は扱わない。

起動は `prototypes/living-nest/` を作業ディレクトリとして `node server.cjs`。新旧計7ファイルだけを配信し、QA・個人保存・設計文書は404。
