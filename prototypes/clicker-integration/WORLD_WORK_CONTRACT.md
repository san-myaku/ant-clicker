# 巣・地層・探索・仕事・保存の共通契約

2026-10-23。対象 `/clicker/`。現在実装した範囲と後続の大人口モデルを区別する。

## 現在の責務

| 状態 | 正本 | 更新できる処理 | 参照する処理 |
|---|---|---|---|
| 土/実空洞 | `nest.air`、2 CSS pxの粒 | 本人の掘削。初期空洞の生成 | 移動、運搬、地形、視界、完成 |
| 地質 | `geology-1` の固定seed/境界/岩/鉱脈 | 新規生成、明示的な旧保存への追加 | 粒の色/硬さ/深度条件/発見 |
| 探索 | `exploration-1` の壁までの距離/発見/到達 | 実空洞の追加、往復可能な作業位置への本人の移動 | 暗さ、HUD、深部敵、鉱脈収入 |
| 建築の目的/費用 | 元本編Gの資源/研究/予約/容量 | 元の雇用/購入/完成処理 | 本編UI、物理的な候補選び |
| 建築の実仕事 | 安定した個体IDに対応する `nest.jobs` | 向かう→掘る/拾う→後退→本人の搬出→荷下ろし | 建築係の動き、同じ荷物、保存 |
| 持ち物 | `Physics.World` の同じ物体ID/採掘元 | 掘って生成、本人が保持、地上で解放 | 地形、描画、数量の照合 |
| 到達/発見報酬 | 探索の到達段階/鉱脈のclaim台帳 | 本人の安全な到達と実搬出 | HUD、元のクッキー台帳、保存 |

描画はこれらを読む。色を変えるために別の地層を作らず、暗くするために土を復活させず、視界を開くために土を消さない。予定の図形から空洞/探索/容量/到達を確定しない。

研究が持つI〜IVの能力、実際に到達した第1〜6層、内部の次の計画帯は別の状態。第5〜6層はIVで掘れる。HUD/敵は到達、仕事の可否は粒の必要能力を使う。研究だけを買っても掘削済みの粒や探索範囲は変えない。

## 仕事の開始と完了

候補の通路と部屋全体の粒を確認し、未解放の地層/岩/用途を含む工事を新しく割り当てない。追加の姿勢確保の掘削にも同じ制限を適用する。予約した特殊室は対象を一つ割り当てる時に予約を一つ消費し、その予約参照を対象へ保存する。

個体は身体と荷の通る帰路を先に確認する。狭い側壁では12pxの後退だけを強制せず、8/4/0pxも実際の荷幅と帰路が通る場合に選ぶ。0pxでも身体/荷が通る姿勢と向きの転換を確認する。未掘削の壁を抜けたり、個体/荷物を移動させ直したりしない。作業面全体を調べても姿勢がない場合は、近傍の必要な粒を本人が掘って運び、姿勢を確保する。

実掘削で空洞へ変わった時に同じ土の実物を作り、本人の取得→本人の地上への搬出→荷下ろし後に進捗を計上する。全対象の実搬出後に元の完成処理を一度だけ呼ぶ。見えている進捗率や時間切れで土を消さない。すでに取得した荷は、旧保存の工事が新しい条件で保留になっても搬出を終える。

## 保存と旧状態

外側は保存基盤の `ant-clicker-grain-save` / schema 1、粒の内側は地質/探索を加えた `clicker-grain-2`。旧 `clicker-grain-1` は形・空洞・個体・仕事・実荷物を保持し、固定した地質を追加する。初期の見通しは実空洞だけから作り、新しい初期配置へ置き換えない。旧データにない地層/探索を追加したことを記録する。

地質の値はCSS座標と固定seed、実世界の幾何は保存DPRから換算する。探索/claim/収入の端数も保存し、再開で二重報酬や失われる端数を作らない。今回の旧保存はQAに保存した直前の確認版の実データで比較する。

画面の更新は通常100ms間隔、直接操作では即時。クッキー発見など進行に関わる判定はシミュレーションでも行い、画面更新間隔から切り離す。毎回の研究盤の再構築に仕事の計算を引きずらせない。

## 大人口と全役割は次の必須工程

今回の実個体/荷物の契約は建築係へ適用した範囲。元本編の `G.ants` と代表アクター/群れは残る。採集・育児・清掃・戦闘の仕事が表示数に依存するA13と、無関係に周回するダミー蟻は未解決。

次はモデル側に安定ID、役割、居場所、担当対象、持物、待機理由と再開条件を持つ軽い個体方式を第一候補にする。実仕事の隊列を集計して個体へ対応させる方式も比較する。各個体の判断、移動、描画の頻度は分け、画面外/表示上限で仕事の人数を変えない。

比較は100/1000/10000人口、同じ地形/役割/在庫/時間で、生産・給餌・清掃・建築の収支、保存後の継続、処理時間/メモリを測る。描画を減らして育児10匹が実働1匹になる結果は不合格。測定せず完成人口を下げたり、群れを再び仕事量の代用にしたりしない。採用方式と達成性能はまだ未決定。

土や在庫の増加は人口と別の軸で測る。運搬物0/1000/5000/20000個について、移動・物理・描画・保存の所要時間と保存容量を分け、同じ実保存から比較する。今回の長い通し試験は4000粒を超えても仕事と荷を継続したが、実機性能/長時間の軽さを合格にした証拠ではない。新規の軽い巣だけで性能を評価しない。
