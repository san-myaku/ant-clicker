## 継承した体験

女王室と入口だけから開始。実働12匹/卵3/餌6。採集した本人が餌を運び、育児係が幼虫へ実給餌し、同じ卵のIDを成長/羽化まで追って働き手が増える。代表個体/群れで人数を水増しせず、人口比例の自動食料加算を使わない。

育児室/食料庫の不足から先端の粒を選び、地層の抵抗・岩・身体/荷の帰路を確認して掘る。用途と方向は持つが、完成形のマスクはない。部屋は実需要/在庫の置かれ方から広げる。掘った同じ物体を本人が地表へ運び、荷下ろし後に容量になる。運び出した土は入口の両側へ左右交互に低い輪として捨て、崩れて広がり、高い列は時間とともに地面に馴染む（台帳で数える）。幼虫は給餌の食べ残しと蛹になる時のメコニウムを実物のゴミとして出し、育児係が地表かゴミ室へ運ぶ。放っておくと成長が遅れ、育児室にたまると病気で働き手が死ぬ。発酵室に運び込んだ実物の餌は甘い粒になり、女王室へ届くとクッキーになる。初期生成/表示/掘削/物理は共通0.25世界単位の粒。

本編由来の8研究を実行動へ接続。採集係の歩速/育児/掘削/女王の産卵/人口上限と深度II〜IV。費用は運搬/予約中を除く実物の餌とクッキー。80粒の実搬出ごとにクッキー1個、初到達した第2層以深で層番号×3個を一度だけ受け取る。旧本編の費用/バランスをそのまま使う段階ではない。

深度Iで第1層、IIで第2層、IIIで第3/4層、IVで第5/6層。境界は36/46/56/66/76付近でうねる。研究購入だけで土/視界/容量/到達は変えない。次の通常計画から深い用途の枝を作り、先端を実際に掘る。実空洞と壁際3単位を明るくし、未知の岩の形を土色へ隠す。
